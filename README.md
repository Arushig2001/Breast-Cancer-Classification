# Breast Cancer Classification using Machine Learning

## Overview

This project uses Machine Learning algorithms to classify breast cancer tumors as malignant or benign using the Wisconsin Breast Cancer Dataset.

## Features

- Logistic Regression
- Random Forest Classification
- Feature Scaling
- Confusion Matrix
- ROC Curve and AUC Score
- Feature Importance Visualization

## Technologies

- Python
- scikit-learn
- NumPy
- Pandas
- Matplotlib
- Seaborn

## Run Project

```bash
pip install -r requirements.txt
python src/breast_cancer_ml.py
```
